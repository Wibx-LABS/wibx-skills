# Manual: Docling Parser Skill

---

#### 🇺🇸 English
**What it does:**
This skill converts documents (PDF, DOCX, PPTX, XLSX, HTML, images) into clean Markdown locally and deterministically using IBM Docling — no LLM tokens spent. It is built for ingesting raw files into Obsidian vaults and LLM wikis.

**Key Features:**
- **Local & Deterministic:** Runs entirely on your machine via IBM Docling; the same input always yields the same Markdown, with zero token cost.
- **Broad Format Support:** Handles PDF, DOCX, PPTX, XLSX, HTML, and images.
- **Vault-Oriented Workflow:** Designed around a raw/inbox folder that gets parsed into Markdown ready for an Obsidian vault or wiki.
- **Configurable Paths:** Source and output directories are easily customized to match any vault layout.
- **Linkable Output:** Produces Markdown files you can link to directly from your notes after ingestion.

#### 🇧🇷 Português
**O que faz:**
Esta skill converte documentos (PDF, DOCX, PPTX, XLSX, HTML, imagens) em Markdown limpo de forma local e determinística usando o IBM Docling — sem gastar tokens de LLM. É feita para ingerir arquivos brutos em vaults do Obsidian e wikis de LLM.

**Principais Recursos:**
- **Local e Determinístico:** Roda inteiramente na sua máquina via IBM Docling; a mesma entrada sempre gera o mesmo Markdown, com custo zero de tokens.
- **Amplo Suporte a Formatos:** Lida com PDF, DOCX, PPTX, XLSX, HTML e imagens.
- **Fluxo Orientado a Vault:** Pensada em torno de uma pasta raw/inbox que é convertida em Markdown pronto para um vault do Obsidian ou wiki.
- **Caminhos Configuráveis:** Diretórios de origem e destino são facilmente ajustáveis para qualquer estrutura de vault.
- **Saída Linkável:** Gera arquivos Markdown que você pode referenciar diretamente das suas notas após a ingestão.
