# Manual: Prompt Engineer Skill

---

#### 🇺🇸 English
**What it does:**
This skill transforms Claude into a professional Prompt Engineer. It provides a systematic framework to gather requirements, analyze task complexity, and build high-quality, production-ready prompts using advanced techniques like Chain of Thought (CoT) and Tree of Thought (ToT).

**Key Features:**
- **Systematic Discovery:** A 9-step discovery process to extract all necessary context (Identity, Persona, Task, Variables, etc.).
- **Complexity Assessment:** Automatically determines if a task requires a single prompt, a multi-prompt workflow, or a collaborative Tree of Thought approach.
- **Advanced Frameworks:** Uses Chain of Thought for step-by-step reasoning and Tree of Thought for complex problem-solving involving multiple AI personas.
- **Production-Ready Output:** Generates clean, copy-paste-ready Markdown templates with embedded reasoning and quality criteria.

---

#### 🇧🇷 Português
**O que faz:**
Esta skill transforma o Claude em um Engenheiro de Prompts profissional. Ela fornece uma estrutura sistemática para coletar requisitos, analisar a complexidade da tarefa e construir prompts de alta qualidade prontos para produção, usando técnicas avançadas como Chain of Thought (CoT) e Tree of Thought (ToT).

**Principais Recursos:**
- **Descoberta Sistemática:** Um processo de descoberta de 9 etapas para extrair todo o contexto necessário (Identidade, Persona, Tarefa, Variáveis, etc.).
- **Avaliação de Complexidade:** Determina automaticamente se uma tarefa requer um único prompt, um fluxo de trabalho de múltiplos prompts ou uma abordagem colaborativa de Tree of Thought.
- **Estruturas Avançadas:** Utiliza Chain of Thought para raciocínio passo a passo e Tree of Thought para resolução de problemas complexos envolvendo múltiplas personas de IA.
- **Saída Pronta para Produção:** Gera templates Markdown limpos e prontos para copiar e colar, com raciocínio embutido e critérios de qualidade.
