# Manual: Frontend Design Skill

---

#### 🇺🇸 English
**What it does:**
This skill produces distinctive, production-grade frontend interfaces with high design quality. Use it when building web components, pages, dashboards, landing pages, posters, or full applications — it generates polished code and UI that deliberately avoids generic "AI-looking" aesthetics.

**Key Features:**
- **Distinctive Aesthetics:** Steers away from cookie-cutter templates toward intentional, opinionated visual design.
- **Production-Grade Code:** Outputs clean, usable HTML/CSS/JS and React components, not throwaway mockups.
- **Broad Surface Coverage:** Websites, landing pages, dashboards, components, artifacts, and posters.
- **Styling & Polish:** Applies considered layout, typography, color, and spacing when building or beautifying any web UI.
- **Composable:** Works alongside frameworks and can style or refine existing interfaces, not only greenfield builds.

---

#### 🇧🇷 Português
**O que faz:**
Esta skill produz interfaces frontend distintas e de qualidade de produção, com alto padrão de design. Use ao construir componentes web, páginas, dashboards, landing pages, posters ou aplicações inteiras — ela gera código e UI polidos que evitam de propósito a estética genérica de "cara de IA".

**Principais Recursos:**
- **Estética Distinta:** Foge de templates padronizados em direção a um design visual intencional e com personalidade.
- **Código de Produção:** Entrega HTML/CSS/JS e componentes React limpos e utilizáveis, não mockups descartáveis.
- **Ampla Cobertura:** Sites, landing pages, dashboards, componentes, artefatos e posters.
- **Estilo e Polimento:** Aplica layout, tipografia, cor e espaçamento bem pensados ao criar ou embelezar qualquer UI web.
- **Combinável:** Funciona junto a frameworks e pode estilizar ou refinar interfaces existentes, não só projetos do zero.
