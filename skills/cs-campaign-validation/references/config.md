# Config: alvos do cs-campaign-validation (placeholders)

Repo público — nenhum ID ou nome real aqui. Resolvidos pelas Project Instructions privadas.

| Placeholder | O que aponta |
|---|---|
| `PLACEHOLDER_APROVADORES_BUDGET` | Quem valida budget/campanha antes de subir (nomes nas instruções privadas) |
| `PLACEHOLDER_KANBAN_TECH` | Kanban onde o card de Tech da campanha deve existir (item 4 do gate) |
| `PLACEHOLDER_DB_CAMPANHAS` | Database oficial de campanhas (onde o parecer do gate é registrado) |

## Fallback

Placeholder ausente: o item correspondente do checklist **reprova por falta de evidência** —
o gate nunca aprova no escuro.
