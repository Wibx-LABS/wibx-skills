# Manual: Refactor Skill

---

#### 🇺🇸 English
**What it does:**
This skill improves the structure and readability of existing code without changing its external behavior. Use it when code is hard to maintain, functions are too large, code smells need addressing, or adding features has become difficult.

**Key Features:**
- **Behavior-Preserving:** Restructures internals while keeping the external contract and outputs identical.
- **Code Smell Detection:** Targets long functions, duplication, poor naming, and tangled responsibilities.
- **Readability First:** Optimizes for maintainability and clarity so future changes are easier.
- **Trigger-Friendly:** Activates on requests like "clean up this code", "refactor this", or "improve this".
- **Incremental & Safe:** Favors small, verifiable structural changes over risky rewrites.

---

#### 🇧🇷 Português
**O que faz:**
Esta skill melhora a estrutura e a legibilidade de código existente sem alterar seu comportamento externo. Use quando o código está difícil de manter, as funções estão grandes demais, há code smells a resolver ou adicionar features ficou difícil.

**Principais Recursos:**
- **Preserva o Comportamento:** Reestrutura o interior mantendo o contrato externo e as saídas idênticas.
- **Detecção de Code Smells:** Mira funções longas, duplicação, nomes ruins e responsabilidades misturadas.
- **Legibilidade em Primeiro Lugar:** Otimiza para manutenibilidade e clareza, facilitando mudanças futuras.
- **Fácil de Disparar:** Ativa com pedidos como "limpa esse código", "refatora isso" ou "melhora isso".
- **Incremental e Seguro:** Prefere mudanças estruturais pequenas e verificáveis a reescritas arriscadas.
